Shipwright is a framework that enables especially non-developers to develop better applications. Since most of them just start prompting, Shipwright helps to structure the whole process 
as if it would be your team PO. It creates from written descriptions structured tickets and lands them in a ticket tool of your choice. 
You can start implementing from within Shipwright, connecting a Coding agent via API and last but not least connect your GitHub to see and review the open Pull Requests. 

Like this you have one single web instance where you can coordinate and control your whole software development flow.
